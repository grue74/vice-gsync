# VICE GitHub Mirror

> **This fork (vice-gsync)** adds smooth VRR/G-Sync video and CRT beam
> simulation, an Ultimate 64 style CPU turbo, Ultimate Command Interface
> emulation and a Visual Studio build. See [FORK-CHANGES.md](FORK-CHANGES.md).

This is the official git mirror of the [VICE subversion repo](https://sourceforge.net/p/vice-emu/code/HEAD/tree/).

For news, documentation, developer information, [visit the VICE website](https://vice-emu.sourceforge.io/).
